# 提高搜索准确率的进阶方法

## 当前实现分析

- **特征提取**：使用 CLS token（第 0 个 token）作为图像特征
- **相似度计算**：余弦相似度（L2 归一化后内积）
- **预处理**：`resize_short_side` 到 224（短边）

## 改进方案（按优先级排序）

### 方案 1：特征池化策略改进 ⭐⭐⭐⭐⭐

**问题**：只使用 CLS token 可能丢失细节信息

**改进**：
- **平均池化所有 patch tokens**：`mean(patches)` 或 `mean(patches[1:])`（排除 CLS）
- **CLS + Patch 融合**：`concat([CLS, mean(patches)])` 或加权平均
- **多层级特征融合**：使用不同层的特征（如第 6、9、12 层）

**预期提升**：+5-10% 准确率

### 方案 2：查询增强（Query Augmentation）⭐⭐⭐⭐⭐

**问题**：单张查询图片可能受角度、光照等影响

**改进**：
- **多尺度查询**：对查询图片做不同尺寸的 resize，提取多个特征后平均
- **数据增强**：水平翻转、轻微旋转、亮度调整等
- **多视图融合**：融合多个增强版本的特征

**预期提升**：+3-8% 准确率

### 方案 3：重排序（Re-ranking）⭐⭐⭐⭐

**问题**：粗检索可能漏掉一些相似图片

**改进**：
- **两阶段检索**：
  1. 第一阶段：快速检索 Top-100（使用 CLS token）
  2. 第二阶段：对 Top-100 使用更精细的特征重排序（如 patch tokens 的细粒度匹配）

**预期提升**：+5-15% 准确率（特别是 Top-10 准确率）

### 方案 4：特征后处理 ⭐⭐⭐

**问题**：特征维度高（768），可能存在噪声维度

**改进**：
- **PCA 降维**：保留 95% 方差的主成分
- **特征选择**：选择区分度高的维度
- **特征标准化**：Z-score 标准化（但可能影响余弦相似度）

**预期提升**：+2-5% 准确率

### 方案 5：相似度度量改进 ⭐⭐⭐

**问题**：余弦相似度可能不是最优的

**改进**：
- **加权余弦相似度**：对不同维度赋予不同权重
- **欧氏距离 + 余弦相似度融合**：`score = α * cosine + (1-α) * (-euclidean)`
- **学习相似度函数**：如果有标注数据，可以训练一个相似度函数

**预期提升**：+2-5% 准确率

### 方案 6：多尺度特征提取 ⭐⭐⭐

**问题**：固定分辨率可能丢失多尺度信息

**改进**：
- **多分辨率特征**：对同一图片提取 224、336、448 等不同分辨率的特征
- **特征融合**：`feat = normalize(feat_224 + feat_336 + feat_448)`

**预期提升**：+3-7% 准确率

### 方案 7：负样本挖掘 ⭐⭐

**问题**：图库中可能有相似但不相关的图片

**改进**：
- **困难负样本挖掘**：在检索时排除明显不相关的类别
- **类别感知检索**：如果知道图片类别，可以先用类别过滤

**预期提升**：+1-3% 准确率（需要额外标注）

## 推荐实施顺序

1. **方案 1（特征池化）**：实现简单，效果明显
2. **方案 2（查询增强）**：实现简单，对查询鲁棒性提升大
3. **方案 3（重排序）**：效果最好，但需要更多计算
4. **方案 4-7**：根据实际效果和需求选择

## 注意事项

- **特征版本管理**：修改特征提取方式后，需要重新构建图库
- **计算开销**：某些方案（如多尺度、重排序）会增加计算时间
- **效果验证**：建议用测试集验证每个改进的效果
