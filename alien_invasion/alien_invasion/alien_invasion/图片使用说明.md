# LaTeX 报告图片使用说明

## 图片文件要求

根据报告中的引用，需要准备以下图片文件：

### 1. UML类图
- **文件名**：`uml_class_diagram.png`
- **内容**：UML类关系图，展示所有类的结构、属性和方法
- **位置**：与 `experiment_report.tex` 同一目录

### 2. 系统交互流程图
- **文件名**：`system_interaction_flow.png`
- **内容**：系统交互流程图，展示游戏主循环中的方法调用流程
- **位置**：与 `experiment_report.tex` 同一目录

### 3. 游戏实机画面
- **文件名**：`gameplay.png`
- **内容**：游戏运行截图
- **位置**：与 `experiment_report.tex` 同一目录

## 如何添加图片

1. **将图片文件放在报告目录下**：
   ```
   alien_invasion/
   ├── experiment_report.tex
   ├── uml_class_diagram.png      ← 放在这里
   ├── system_interaction_flow.png ← 放在这里
   └── gameplay.png                ← 放在这里
   ```

2. **如果图片文件名不同**，可以修改 `.tex` 文件中的引用：
   ```latex
   \includegraphics[width=0.95\linewidth]{your_image_name.png}
   ```

3. **图片格式建议**：
   - 格式：PNG 或 JPG
   - 分辨率：建议 150-300 DPI
   - 大小：UML类图和流程图可以大一些（宽度建议 0.95\linewidth）
   - 游戏截图：根据实际情况调整（当前设置为 0.92\linewidth）

## 编译报告

使用 XeLaTeX 编译：
```bash
xelatex experiment_report.tex
```

如果图片文件找不到，编译时会提示错误，请检查：
1. 文件名是否正确
2. 文件路径是否正确
3. 文件格式是否支持

## 提示

- 如果图片太大导致页面放不下，可以调整 `width` 参数（如改为 `0.85\linewidth`）
- 如果图片分辨率不够，可以先调整图片大小再插入
- 建议使用高质量的截图或导出的图片，确保在 PDF 中清晰可见
