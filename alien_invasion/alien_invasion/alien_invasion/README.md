# 外星人入侵 (Alien Invasion)

一个使用 Pygame 开发的经典太空射击游戏，支持多种游戏系统增强。

## 游戏简介

玩家控制一艘飞船，在太空中与外星人舰队战斗。通过击败外星人获得分数和经验值，升级角色属性，解锁新技能和装备，挑战更高难度的关卡。

## 操作说明

### 基本操作
- **方向键**：控制飞船移动
- **空格键**：发射子弹
- **P键**：暂停/继续游戏
- **Q键**：退出游戏
- **U键**：释放大招（充能满时）

### 游戏机制
- **连击系统**：在短时间内连续击败外星人可以获得连击加成，提高分数
- **升级系统**：击败外星人获得经验值，升级后可以选择属性提升
  - 击败每个外星人获得10点经验值
  - 经验值达到上限后升级，显示升级选择界面
  - 可升级属性：
    - **攻击力**：每级增加10%伤害（影响子弹速度）
    - **射速**：每级减少5%射击间隔（最高减少70%）
    - **移动速度**：每级增加8%移动速度
    - **生命上限**：每级增加1条生命
    - **子弹数量**：每级增加50个同时可发射的子弹上限（最高500）
- **大招系统**：击败外星人积累充能，充能满后可释放强力大招
  - 每击败30个外星人，大招充能达到100%
  - 充能条显示在屏幕底部中央
  - 按U键释放大招（随机选择一种大招类型）
  - 大招类型：
    - **核爆**：立即清除所有敌人，每个敌人100分
    - **时间停止**：暂停敌人移动5秒
    - **流星雨**：发射20枚追踪导弹
    - **激光束**：持续3秒，所有射击变为激光
- **宝箱系统**：通关后有机会获得宝箱奖励
  - 每5关必得宝箱，其他关卡30%概率获得
  - 宝箱类型根据关卡等级动态生成（普通/稀有/史诗/传说）
  - 宝箱奖励包括：
    - **装备**：根据宝箱品质生成不同品质的装备
    - **经验值**：根据玩家等级和宝箱品质计算
    - **金币**：预留接口（未来功能）
    - **技能书**：预留接口（未来功能）
  - 奖励界面显示3秒，可按空格键或回车键跳过
