## 🔍 技术细节

### 时区转换

Django 会自动处理时区转换：
- 数据库存储：UTC 时间
- 显示：根据 `TIME_ZONE` 设置转换为本地时间
- 模板中使用 `timezone.localtime()` 确保正确显示

### 日期格式优先级

Django 使用以下优先级：
1. 模板中的自定义格式（如 `{{ date|date:'Y年m月d日' }}`）
2. `settings.py` 中的格式设置
3. 默认格式

### 管理后台自定义

使用 Django Admin 的装饰器和类属性：
- `@admin.register()` - 注册模型
- `list_display` - 列表显示字段
- `list_filter` - 筛选字段
- `search_fields` - 搜索字段
- `fieldsets` - 字段分组
