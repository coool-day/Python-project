## 📝 使用说明

### 开发环境

静态文件和媒体文件会自动提供服务，无需额外配置。

### 生产环境部署

1. **收集静态文件**：
   ```bash
   python manage.py collectstatic
   ```
   这会将所有静态文件收集到 `staticfiles/` 目录。

2. **配置 Web 服务器**：
   - 配置 Nginx 或 Apache 提供静态文件服务
   - 静态文件路径：`/static/` → `staticfiles/`
   - 媒体文件路径：`/media/` → `media/`

3. **环境变量设置**：
   - 确保 `DEBUG=False`
   - 配置 `ALLOWED_HOSTS`

## 🔧 添加新的静态文件

### 添加 CSS 文件
1. 将文件放入 `static/css/` 目录
2. 在模板中引用：
   ```django
   {% load static %}
   <link rel="stylesheet" href="{% static 'css/your-file.css' %}">
   ```

### 添加 JavaScript 文件
1. 将文件放入 `static/js/` 目录
2. 在模板中引用：
   ```django
   {% load static %}
   <script src="{% static 'js/your-file.js' %}"></script>
   ```

### 添加图片文件
1. 将文件放入 `static/images/` 目录
2. 在模板中引用：
   ```django
   {% load static %}
   <img src="{% static 'images/your-image.png' %}" alt="描述">
   ```

## 📌 注意事项

1. **生产环境部署**：
   - 必须运行 `collectstatic` 收集静态文件
   - 配置 Web 服务器提供静态文件服务
   - 不要使用 Django 开发服务器提供静态文件（性能差）

2. **媒体文件安全**：
   - 生产环境应配置适当的文件上传限制
   - 验证文件类型和大小
   - 防止恶意文件上传

3. **缓存策略**：
   - 静态文件可以设置长期缓存
   - 使用版本号或哈希值更新缓存
